# V1 release review

This is a manual checklist; no automatic publication executor is bundled.

1. Freeze project, dataset, protocol, target, environment and scorer identities.
2. Verify input count, unique IDs, SHA-256, provenance and redistribution rights.
3. Check task-set coverage, native denominator units and all invalid/unknown records.
4. Preserve public execution/private scoring separation and evidence lineage.
5. Require acceptance evidence for new tasks; candidates remain unaccepted until reviewed.
6. Match native summaries and reports to the reviewed result files.
7. Save a completed release manifest with reviewer decision and destination.
