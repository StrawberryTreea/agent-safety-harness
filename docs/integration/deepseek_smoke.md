# DeepSeek 普通 LLM 工程测试

此入口只验证真实 API 调用、原生规则评分和用量记账。固定使用仓库的三条 synthetic_plumbing_demo 工程样例，不是安全基准、Agent 执行或回路A有效性实验，不改动正式实验协议。

默认离线，仅生成计划：

```powershell
python scripts/run_deepseek_smoke.py
```

获得人工付费授权并在执行进程配置 `DEEPSEEK_API_KEY` 后，才可显式启用真实调用：

```powershell
python scripts/run_deepseek_smoke.py --live
```

固定官方 HTTPS 地址、`deepseek-flash`、关闭思考模式、每次最多输出32个Token。一次运行计划3次请求，无自动重试，拒绝重定向，拒绝复用任何已存在的输出目录。身份绑定输入文件、实际消息、参数、执行器和原生评分器代码哈希。请求不含参考答案字段。

预算账本固定最多10次请求、5元人民币，每次发送前预留0.5元并计1次；正常计划只有3次。此限制是每个运行目录的限制；人工重新执行到新目录也会产生费用，不能把多个目录当成同一个全局预算。不要在原授权耗尽后自行重新执行。

按[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)（核对日期2026-10-23），统一采用高峰价格：输入缓存命中0.04元/百万Token，未命中2元/百万Token，输出8元/百万Token，逐请求向上取整到微元。`usage_priced_upper_microcny` 是API用量按高峰价格的保守估算，不是平台账单；低峰实际单价减半。单次预留是工程预算控制，不是服务商扣费保证；若服务商返回超预留费用，记录实际估算并锁定后续派发。

遇超时、HTTP错误、用量缺失或矛盾即停止，保留未知费用预留，不重试。不保存异常原文或HTTP错误响应体。完整回答无法抽取答案时按原生规则算失败；截断、空回答、非文本响应及非空回答对应零输出用量为无效执行，单列且不计通过。返回模型必须与请求模型名一致，后端指纹必须非空且在本轮保持一致；不满足则结算已报告的用量、停止并记录无效原因，不将本轮不同后端混入有效分母。指纹一致只是可观测一致性，不保证平台内部权重不变。

请求次数或费用预算不足时，在下一次发送前停止并保存 `stopped_budget` 摘要。JSON计划和摘要使用同目录临时文件、刷新并原子替换；替换失败时保留上一份完整JSON。账本是逐请求费用证据，强制中断可能留下 `running` 摘要和未结算预留，旧目录仍拒绝重跑，需要人工核对。

输出位于被Git忽略的 `runs/deepseek-smoke-*`：`request_plan.json`、`run_identity.json`、`budget.sqlite3`、`results.jsonl`、`summary.json`。默认不提交或推送。

离线回归（不调用API）：

```powershell
python -m unittest tests.test_deepseek_smoke tests.test_deepseek_faults -v
```

## 2026-10-23首次真实验证

在用户授权最多10次请求、5元预算后，实际只发送3次，无重试。3次API成功、3条完整回答均被原生评分器判通过，API错误及无效执行均为0；总输入108 Token、输出3 Token。按冻结高峰单价估算费用上界为240微元（0.00024元），未查询平台账单。平均每次约1.64秒。三次返回模型名均为 `deepseek-flash`、后端指纹相同，原始请求ID和指纹保留在本地结果中。

用户随后反馈平台显示此前花费0.01元，故此前Token估算不能代表平台账单。后续[受控实际试验](deepseek_pilot.md)单独记录账户余额变化、估价和保守预算占用，避免混用。

离线预算/异常回归9项通过，包括默认不调用、密钥缺失、重复目录拒绝、私有答案字段隔离、费用未知保留预留、费用超预留停止、缺失/矛盾用量、截断回答和原生失败分母。三题通过只证明工程连通，不能推导DeepSeek安全性、Agent能力或测试集进化收益。

## 2026-10-23故障注入补强

新增10项离线故障测试，连同前述9项共19项通过。测试先复现了模型身份不匹配仍计分、后端指纹漂移仍合并结果、非空回答与零输出用量矛盾仍通过、预算不足未保存终态、JSON非原子覆盖五类问题，再验证修复。

HTTP层测试在127.0.0.1临时服务器运行，使用虚拟密钥，实际验证307重定向拒绝、429限流、非法JSON和超大响应；不连接DeepSeek或使用真实密钥。401/500/503、KeyboardInterrupt中断重跑、畸形choices、预算边界和磁盘替换失败通过故障注入验证。测试中的 `--live` 函数参数仅用于进入派发路径，实际传输被注入为本机服务器或合成响应，本次新增付费调用为0。
